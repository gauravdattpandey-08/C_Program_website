Questions

Question 1 : Q1. Write a C program using recursion to display numbers from 1 to 5. Use a global variable i initialized to 1.

Solution:

    #include <stdio.h>
    int i = 1;

    void display()
    {
        if (i <= 5)
        {
            i++;
            display();
            printf("%d", i);
        }
    }

    void main()
    {
        display();
    }

Output:

666666
